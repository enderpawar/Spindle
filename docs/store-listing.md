### 데이터 안전(Data Safety) 답변표

Google Play의 "수집"은 사용자 데이터가 기기 밖으로 전송되는지를 기준으로 답한다. Spindle의 위치·방위 계산과 방문 기록·설정 저장은 모두 기기 안에서만 이루어진다.

| 데이터 유형 또는 항목 | 수집 여부 | 공유 여부 | 답변 근거 |
| --- | --- | --- | --- |
| 위치정보 — 대략적 위치 | **수집함** | 공유 안 함 | Spindle 자체는 좌표를 전송하지 않는다(방향·거리·권역 계산은 전부 단말 내). 다만 **카카오맵 SDK가 지도 타일을 요청할 때 조회 지역이 카카오 서버로 전달**되므로, 제3자 SDK의 수집까지 신고 대상으로 보는 Play 기준에 맞춰 "수집함"으로 답한다. 목적은 **앱 기능**, **추적 아님**, 사용자 삭제 요청 대상 아님(저장하지 않음). |
| 위치정보 — 정확한 위치 | 수집 안 함 | 공유 안 함 | 정확한 GPS 좌표는 단말 밖으로 나가지 않는다. 카카오맵에는 지도 중심 기준의 지역 조회만 발생한다. |
| 모션·방위 센서 정보 | 수집 안 함 | 공유 안 함 | 나침반 방향 추천에 단말 내에서만 사용하며 서버로 전송하지 않는다. |
| 개인 정보(이름, 이메일, 전화번호 등) | 수집 안 함 | 공유 안 함 | 회원가입·로그인·계정이 없고 개인식별정보를 입력받지 않는다. |
| 앱 활동 및 사용자 생성 콘텐츠 | 수집 안 함 | 공유 안 함 | 사용자 생성 콘텐츠가 없으며 방문 관광지 식별자는 기기 내부에만 저장된다. |
| 기기 또는 기타 식별자 | 수집 안 함 | 공유 안 함 | 분석·추적 SDK를 사용하지 않는다. |
| 금융 정보 및 구매 내역 | 수집 안 함 | 공유 안 함 | 광고와 인앱결제가 없다. |

관광지 정보는 자체 Cloudflare Workers 프록시를 거쳐 한국관광공사 TourAPI에서 실시간으로 받아온다. 프록시는 API 키 주입과 요청 중계만 하며 사용자 좌표를 받거나 사용자 정보를 저장하지 않는다.

#### 카카오맵 SDK — 처리 결론 (2026-08-14 확정)

Spindle 자체는 좌표를 전송하지 않지만, **지도 표시에 카카오맵 JS SDK를 사용**한다.
현장 모드에서 지도를 현재 위치 기준으로 그릴 때 `KakaoMapView`가 그 좌표로 지도 중심을 잡으므로,
해당 지역의 지도 데이터를 요청한다는 사실이 카카오 서버에 전달된다. 길찾기 링크에는
목적지 관광지 좌표만 담기며 사용자 현재 위치는 넣지 않는다(`web/src/lib/mapLinks.ts`에 고정).

양대 스토어 모두 **앱에 포함된 제3자 SDK의 수집까지 신고 대상**으로 본다.
카카오맵을 앱에서 빼는 대신 **있는 그대로 신고하는 쪽**을 택했다 — 지도 품질을 유지하고
웹 배포본과 동작을 일치시키기 위해서다. 확정 답변:

- Google Play Data Safety: **위치 → 대략적 위치 = 수집함 / 공유 안 함 / 목적 = 앱 기능 /
  추적 아님 / 전송 중 암호화됨(HTTPS) / 삭제 요청 대상 아님(저장하지 않음)**.
  정확한 위치는 "수집 안 함".
- Apple App Privacy: **"데이터를 수집하지 않음"을 선택하지 않는다.**
  "위치 - 대략적 위치"를 "앱 기능" 목적으로 신고하고, 사용자 신원과 연결되지 않으며
  추적에 사용하지 않는다고 답한다.
- 개인정보처리방침 5절에 이 내용이 이미 명시돼 있다(`web/public/privacy.html`).
  스토어 답변과 방침 문구가 어긋나지 않게 함께 유지한다.

> 대안이었던 "앱 빌드에서 카카오맵을 빼고 `LocalMapView` 폴백만 사용"은 채택하지 않았다.
> 필요해지면 SDK 로드 실패 경로가 이미 있으므로 되돌릴 수 있다.

### 심사 노트(App Review Notes)

> Spindle은 로그인이 필요하지 않으며 앱 실행 후 바로 이용할 수 있습니다.
>
> 심사자가 부산 밖에 있어도 여행 모드로 전체 기능을 체험할 수 있습니다.

> 2. 출발점 선택 화면으로 이동합니다.

> 4. 선택한 출발점을 기준으로 방향 추천을 실행하고, 추천 결과와 방향 기반 코스, 도장깨기, 공유 카드를 확인합니다.
