# 앱 글꼴 굵기 정리 — 2026-09-07

사용자가 Pretendard를 유지하고 앱 전체 글꼴 위계를 정리하는 제안을 승인했다. 기존 화면·컴포넌트와 CSS 19개 파일에서 굵기 선언만 조정했다.

- 주요 화면 제목은 800으로 유지하고 기존 850~900의 강한 강조를 줄였다.
- 대표 테마 카드 제목은 750, 장소 카드 제목은 주로 700으로 조정했다.
- 공통 스핀·테마·명소 메뉴는 기본 600, 선택 700으로 구분한다. 하단 내비게이션도 600/700을 사용한다.
- 보조 설명과 출처는 주로 500~550으로 조정했다. 버튼은 기존 강조를 완화하면서 대체로 650~700을 사용한다.
- 폰트 파일·크기·색상·줄 높이·간격·내용·기능은 변경하지 않았다.

작업 전 각 파일의 사본과 비교하여 이번 편집이 굵기 선언에만 한정됨을 확인했다. 이미 존재하던 다른 변경은 유지했다. 사용자 요청이 앱 전체 타이포그래피를 대상으로 하므로 미커밋 변경이 있는 화면에도 해당 선언만 수정했다.

검증: 전체 check 통과(web 388개 + proxy 26개 테스트, 타입 검사·lint·guard), 프로덕션 빌드 통과. 기존 Fast Refresh 경고는 유지된다. 연결된 브라우저가 없어 실제 줄바꿈·실기기 가독성은 육안 검증하지 못했다. 로컬 수정이며 배포하지 않았다.
