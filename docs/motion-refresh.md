# 일상 화면 모션 정리 — 2026-09-07

사용자가 승인한 방향: 선택·누름·사진 전환은 짧고 차분하게, 핵심 스핀·도장 획득은 유지한다.

- 메뉴 색·배경 전환은 기존 150ms를 유지했다.
- 테마 대표 카드는 테마 변경 시 200ms 불투명도 전환을 사용한다. 확대·이동은 추가하지 않는다.
- 사진 준비 후 페이드는 420ms에서 200ms로 단축했다.
- 목록 카드의 순차 등장과 지연을 제거했다. 독립적인 결과 정보 영역의 등장은 200ms 페이드로 단순화했다.
- 일반 버튼·카드의 복귀는 140ms ease-out, 눌림은 98~98.5% 축소로 완화했다.
- 캐러셀의 240ms 슬라이드, 스핀 엔진·결과 공개·도장 획득 모션은 유지했다.
- 모션 감소 설정은 기존 전역 규칙을 유지하며 테마 카드의 새 애니메이션도 명시적으로 끈다.

검증: 전체 check(web 388개 + proxy 26개 테스트, 타입 검사·lint·guard) 및 프로덕션 빌드 통과. 연결된 브라우저가 없어 실제 전환의 육안·실기기 검증은 수행하지 못했다. 로컬 변경이며 배포하지 않았다.
