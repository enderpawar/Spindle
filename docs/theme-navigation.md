# Phase 7 테마 선택 바 디자인 수정 — 2026-09-07

사용자 요청: 테마로 떠나기 상단 선택 바를 스핀의 관광지·음식점·카페 메뉴와 같은 디자인으로 맞춘다.

- 기존 `spin-category-switch` 버튼 스타일을 공유한다. 선택 항목만 흰 캡슐·옅은 파란 테두리·파란 글자로 표시하고 비선택 항목은 투명 배경으로 표시한다.
- 이모지 대신 파도·시장·역사 건물·달·식기 선형 SVG를 사용한다. 테마 이름과 본문의 테마 그래픽은 유지한다.
- 버튼은 기존 메뉴와 같은 46px 높이이며, `aria-pressed`와 키보드 포커스 표시를 제공한다.
- 다섯 테마는 가로 스크롤로 배치한다. 선택 항목이 잘리면 선택 바 안에서만 위치를 조정하며 본문 스크롤 위치는 바꾸지 않는다.
- `ThemeNavigation` 컴포넌트와 전용 CSS로 구성했다. 다른 작업의 미커밋 변경이 있는 `index.css`, `SPEC.md`, `docs/ui.md`, `PLAN.md`는 수정하지 않았다. 이 문서는 해당 테마 덱 명세의 보완 기록이다.

검증: 프로덕션 빌드 통과. 연결된 브라우저가 없어 실제 화면·모바일 터치 검증은 수행하지 못했다. 로컬 소스 변경이며 배포하지 않았다.

## 테마 대표 카드 후속 시안

사용자가 밝은 세로형 카드 제안을 적용해 보도록 요청했다. `ThemeHero` 컴포넌트로 사진 위·정보 아래 구성을 적용했다.

- 사진은 2:1 비율로 카드 너비를 채우며 사선 경계와 어두운 덮개를 제거한다.
- 흰 정보 영역에 테마별 제목, 장소 수와 여행 장면 수, 전체 너비의 파란 시작 버튼을 배치한다.
- 카드 위의 중복 테마 요약·장소 수 행은 제거한다. 이모지 대신 사진이 없을 때만 옅은 선형 배경을 보여준다.
- 기존 테마 선택·대표 사진 조회·시작 콜백·후보 없음 시 비활성화 동작을 유지한다.
- `index.css`의 다른 작업 변경을 보존하기 위해 전용 CSS를 사용했다. 기존 카드 CSS는 다른 사용처와의 충돌을 피하기 위해 이번 작업에서 삭제하지 않았다.

프로덕션 빌드 통과. 화면 육안 검증은 수행하지 못했다.

## 명소 메뉴·사진 뷰어 후속 요청

- 명소의 전체·음식점·카페 선택 메뉴에 지도 핀·식기·커피 선형 아이콘과 동일한 선택 캡슐 스타일을 적용했다. 종류 및 지역 필터 동작은 유지하며 좁은 화면에서는 지역 선택이 다음 줄로 내려가 겹치지 않게 한다.
- 사진 뷰어의 이전·다음 버튼을 사진 영역 좌우 중앙에 배치했다. 흰 반투명 44px 원형 버튼으로 사진 위에서도 구분하며, 움직이는 사진 트랙 밖에 두어 전환 중에도 고정한다. 사진 순서·출처는 아래에 유지한다.
- 기존 버튼 클릭·키보드·스와이프·취소 흐름을 유지한다. 버튼 영역은 기존 포인터 처리의 button 제외 조건을 사용해 드래그와 충돌하지 않는다.
