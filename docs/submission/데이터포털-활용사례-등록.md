## 2. 활용사례 설명

```
휴대폰을 돌려 나침반이 가리키는 방향의 부산 원도심·영도 관광지를 추천하는 웹 서비스입니다. 한국관광공사 TourAPI(KorService2)의 areaBasedList2로 중구·동구·서구·영도구의 관광지 목록을, detailCommon2·detailIntro2·detailImage2로 상세 정보와 사진을, searchFestival2로 축제·행사 정보를 실시간 조회해 제공합니다. 인기 명소에 쏠리는 방문을 방향과 접근성 기준으로 분산시켜, 잘 알려지지 않은 관광지를 발견하도록 돕는 것이 목표입니다.

사용자의 GPS 좌표와 방위각은 단말 안에서만 계산하며 서버로 전송하지 않습니다. TourAPI 응답은 세션 메모리에만 두고 별도 저장소에 적재하지 않습니다.

Google Play와 App Store에도 동일 서비스를 출시했으며, 웹(PWA)·Android·iOS 모두 같은 TourAPI 실시간 호출 경로를 사용합니다.

출처: ⓒ한국관광공사
```

## 3. 기능 및 서비스 화면

첨부 이미지는 `docs/screenshots/` 의 `a01`·`a02`·`a04`·`a08` 4장을 순서대로 사용한다.
(2026-09-11 프로덕션 재촬영본. 같은 디렉터리의 나머지 캡처는 기능설명서 부록 A용이다.)

### a01-home.png — 홈 / 탐색 시작

```
출발점(예: 부산역)을 고르고 바로 스핀을 시작하는 첫 화면입니다. 명소·도장깨기·여행모드·축제 바로가기와 바다·골목시장·근현대역사·야간·먹거리 5개 테마 덱, 추천 여행지 카드, 원도심 도장깨기 진행률을 제공합니다. 추천 여행지의 관광지 정보와 사진은 한국관광공사 TourAPI로 실시간 조회합니다.
```

### a02-spin.png — 방향 스핀

```
8방위 원판을 돌려 오늘 갈 방향을 정하는 핵심 기능입니다. 이동 시간 슬라이더(20분~제한 없음)로 탐색 반경을 조절하고, 원판을 밀거나 휴대폰을 흔들어 무작위 방향을, 나침반 모드로 실제 단말이 향한 방향을 사용합니다. 관광지·음식점·카페 중 무엇을 찾을지도 함께 고를 수 있습니다. GPS 좌표와 나침반 방위각은 모두 단말 안에서만 계산하며 서버로 전송하지 않습니다.
```

### a04-result.png — 추천 결과 카드

```
선택된 방향에서 찾아낸 관광지를 사진·소개·주소·방문 정보로 보여줍니다. 관람시간·휴무일·이용요금·주차 정보는 detailIntro2, 소개 글과 주소는 detailCommon2, 사진은 detailImage2로 실시간 조회하며, 화면 하단에 '출처: ⓒ한국관광공사'를 표기합니다. 마음에 들지 않으면 다른 후보로 넘기거나, 같은 방향으로 코스를 이어서 만들 수 있고, 카카오맵 길찾기와 공유 카드로 연결됩니다.
```

### a08-course-guide.png — 방향 기반 여행 코스 안내

```
스핀한 방향을 따라 가까운 관광지 2~4곳을 순서대로 이은 코스입니다. 지도에 출발점과 방문 순번 핀을 함께 표시하고, 단계별로 카카오맵 길찾기를 연결해 이동을 안내합니다. 조건에 맞는 장소가 부족하면 억지로 채우지 않고 가능한 만큼만 코스를 구성했음을 사용자에게 알립니다. 인기 명소에 몰리지 않도록 방향·접근성·분산 가중치를 함께 반영해 장소를 배치합니다.
```
