## 핵심 규정 (FAQ 확인 사항)

1. **TourAPI 실시간 호출만 인정.** 로컬 DB 적재는 별도 신청서 필요, 파일 데이터는 불인정 → Spindle은 실시간 호출로 설계 (신청서 경로 사용 안 함).
2. **운영계정 인증키 기준으로 개발 기간 중 실제 호출 이력을 검증** → 개발 첫 주부터 운영계정 키 사용.
3. 생성형 AI 사용에 따른 감점 없음.
4. 웹 서비스는 URL 제출로 심사 (앱스토어 등록 불필요).
5. **서비스 소유권은 참가자에게** 있으며 공사는 개발 서비스를 운영하지 않는다. 서비스명·브랜딩에 기관명 또는 공식 CI/BI 로고 이미지를 사용해 공사가 직접 개발·운영하는 것처럼 오인시키는 표기는 금지.
6. **공공데이터 출처 텍스트 표기는 필수.** `출처: ⓒ한국관광공사` 또는 `출처: ⓒ한국관광콘텐츠랩`으로 표기한다. `TourAPI`만 단독 출처로 표기하는 방식은 지양.
