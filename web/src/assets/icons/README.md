# 아이콘 에셋

Spindle UI 아이콘 원본. 레퍼런스는 **8방위 나침반 로즈 + 지도 핀**의 결합, 플랫 2톤 블루다.

색은 `web/src/index.css`의 `:root` 토큰만 쓴다. 그라디언트·필터·`id`는 쓰지 않는다
(한 페이지에 여러 개 인라인될 때 `id`가 충돌하고, 16px에서 필터는 뭉갠다).

## 색 규칙

| 파일 | 색 처리 |
|---|---|
| `nav-*.svg` | 전부 `currentColor` — 호출부가 활성 `#1e4fd8` / 비활성 `#9db3d8`를 준다 |
| `pin-curated.svg` · `pin-spot.svg` | 몸통 `currentColor` — 8방위 색이 주입된다 |


핀 속지는 고정색이다. 주입되는 8방위 색이 밝은 파스텔(`#ffd166` 동, `#7ee0c3` 북동)이라
흰색 속지는 묻힌다 — 큐레이션 핀은 흰 별 + `#17347f` 외곽선, 일반 핀은 `#17347f` 점을 쓴다.

## 목록

| 파일 | viewBox | 용도 |
|---|---|---|
| `nav-home.svg` | 24 | 하단 네비 — 홈 |
| `nav-spots.svg` | 24 | 하단 네비 — 명소 (핀 속에 4방위 별) |
| `nav-stamp.svg` | 24 | 하단 네비 — 도장 |
| `nav-settings.svg` | 24 | 하단 네비 — 설정 (슬라이더) |
| `pin-curated.svg` | 30×38 | 지도 — 큐레이션 명소 |
| `pin-spot.svg` | 18×23 | 지도 — 관광공사 등록 명소 (낮은 위계) |

## 쓰는 법

`currentColor`가 살아야 하므로 `<img src>`로 불러오면 안 된다 (색이 안 먹는다).
인라인 `<svg>`로 넣거나 React 컴포넌트로 감싸 쓴다. `width`/`height` 속성이 없으므로
호출부에서 지정한다.

## 검수 기준

바꾸거나 추가할 때는 **실제 렌더 크기**(네비 24px, 큐레이션 핀 16~30px,
일반 핀 14~18px)로 흰 배경·지도 배경에 얹어 눈으로 확인한다. 3배 확대만 보고 통과시키지 않는다 —
지금까지 반려된 사유가 전부 축소 시에만 드러났다(요소 겹침, 속지 대비 부족, 자물쇠로 오독).

## 스핀 나침반은 여기 없다

스핀 화면 원판은 `components/CompassRose.tsx`가 직접 그린다. 회전부(눈금 링·4방위 날·라벨)와
고정부(중앙 보스·로고·12시 주황 인덱스)를 코드에서 분리해야 하고 라벨을 매 프레임 역회전시켜야
해서, 정적 SVG 파일로 둘 수 없다. 디자인 근거는 `docs/design/ocean-compass/RESEARCH.md`.
